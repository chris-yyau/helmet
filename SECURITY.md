# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Email:** security@diveanddev.com

**Response timeline:**
- **48 hours** — acknowledgment of your report
- **1 week** — initial assessment and severity classification
- **30 days** — target for fix and disclosure (may vary by severity)

## Scope

- All code in this repository
- Dependencies used by this project
- CI/CD pipeline configuration

## Recognition

We appreciate responsible disclosure and will credit reporters in the fix commit (unless you prefer to remain anonymous).

## Out of Scope

- Issues in upstream dependencies (report to the upstream project)
- Social engineering attacks
- Denial of service attacks
